# Mod safety in plain rules

Mods are the grown-up joy of making a game more *yours* — a different
look, a kinder font, a quality-of-life fix a patch never brought. They are
also the number-one way people accidentally break a game they love, or
worse, install something that was never a mod at all. This chapter is in
plain rules you can follow in one sitting — the same tone as everything
else in this manual ([mod](glossary.md#mod),
[mod manager](glossary.md#mod-manager), glossary first if a word scares
you).

## The plain rules

1. **Single-player default.** Mods belong in single-player and offline
   play. In team games with anti-cheat, third-party files can get your
   account banned even when you meant no harm. Default to closed doors.
2. **Official-first sources.** Download mods from the game's official
   workshop, or from large respected mod sites with user votes and
   reports (Nexus-style). Never from a random download site, a chat
   message, or a "click here to get the mod" video description.
3. **Read the page before you download.** One minute: what does it do,
   what game and version does it require, when was it last updated,
   what do comments say about conflicts?
4. **Know your file types.** Good mod packages contain archives, text
   configs, asset files. An `.exe`, `.bat`, or installer "mod" from a
   non-official site is a red flag the size of a barn.
5. **Update your antivirus and let it scan.** Let it read the archive
   before you open it. If it barks, stop and investigate; a mod is
   never worth an account.
6. **Back up first.** Copy the save
   ([chapter 4](ch-04-save-backups.md)), then install the mod. Mods
   rarely destroy saves, but they can change the game so much that the
   save needs the mod forever — and a backup keeps that choice open.
7. **One mod at a time.** Install, run the game a few minutes, then add
   the next. When something breaks (and eventually it does), you know
   exactly which change did it. Keep a small `mods.txt` note listing
   what you added — like
   [save-locations.txt](ch-04-save-backups.md#what-a-save-file-is),
   future-you will be grateful.
8. **Use a mod manager.** A manager ([mod
   manager](glossary.md#mod-manager)) installs in one place, tracks
   everything, and *uninstalls cleanly* — meaning "the game returns to
   how it was before," which is the whole safety win.
9. **Uninstall before patch day.** Before a game's big official update
   ([patch](glossary.md#patch)), remove or disable your mods, update
   clean, verify the game works, then re-add mods when their authors
   have updated them.
10. **Respect other players.** Anything that changes your experience in
    a *shared* game (see-through walls, auto-aim, faster cooldowns) is
    cheating real humans out of honest fun — the one rule with no
    grown-up exceptions.

> A mod you are slightly worried about is not a mod you install. There
> is no game worth your machine feeling like someone else's.

## The FFXIV special case

Final Fantasy XIV deserves its own honest paragraph here, because it is
different from most games:

- **There are no official mods for FFXIV.** The maker does not support
  third-party modifications or add-ons of any kind, and using them
  violates the game's user agreement. Players have been penalized for
  it, particularly when tools affect gameplay or are discussed publicly
  in-game.
- **What moderation of look officially exists** is in-game and rich:
  the [glamour](glossary.md#glamour) dress-up system, trades of fashion
  items, and in-game photo tools cover most of the "I want my character
  to look like *this*" desire.
- **Plugins that change combat behavior, timers, or information**
  simply do not have grown-up intentions (even when the tool is
  written kindly). If you choose to walk close to this line, you do so
  at real risk to your account, and this manual politely declines to
  be the map for it.

## If something feels off after a mod

- Uninstall the mod (with the manager; see rule 8), run the game, and
  see if it is better.
- If your machine is misbehaving in general browser-and-hearth ways —
  slow boots, pop-ups, a browser homepage you did not choose — treat
  that as an entirely separate problem (real-world anti-virus scan,
  and lean on a technical friend rather than a random cleanup tool).
- Your [saves](ch-04-save-backups.md#what-a-save-file-is) and your
  accounts should never leave the machine; if they do, change
  passwords everywhere and write down which mod did it, to make sure
  that mod is never reinstalled.
